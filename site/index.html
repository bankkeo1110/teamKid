Một đội phần mềm toàn AI, làm việc theo Scrum trên máy của bạn

Bạn nói yêu cầu với KID. Product Owner viết spec cho bạn duyệt, các Developer code song song, Tester dùng thử, KID báo lại kết quả. Mọi việc nằm trên GitHub Issues để bạn theo dõi.

Bản mô phỏngTeam giả lập chạy ngay trên trình duyệt. Bấm 2D / 3D để đổi, kéo để xoay văn phòng.

Cài đặt trên Windows

Mở PowerShell (bấm Start, gõ PowerShell) rồi dán lệnh này. Trình cài tự làm phần còn lại và chỉ dừng khi cần bạn.

irm https://raw.githubusercontent.com/bankkeo1110/teamKid/main/install.ps1 | iex
  1. Bấm Yes khi Windows xin quyền cài WSL. Có thể phải khởi động lại, trình cài tự chạy tiếp.
  2. Đặt tên và mật khẩu cho tài khoản Linux bên trong máy.
  3. Đăng nhập Claude và GitHub trên trình duyệt khi được hỏi.
  4. Trả lời câu hỏi cấu hình: tracker GitHub, mã ticket KID. Xong thì mở Start KID trên Desktop.

Cần Windows 10 (bản 2004 trở lên) hoặc Windows 11, tài khoản Claude Pro hoặc Max, và một tài khoản GitHub. Team chạy trên máy bạn, dùng lượt Claude của bạn; trang này chỉ là bản giới thiệu.

Thành viên

Mỗi thành viên là một phiên Claude Code riêng, có hợp đồng vai trò và chỗ ngồi riêng trong herdr.

KID

Scrum Master

Người duy nhất bạn nói chuyện. Đọc bảng việc, giao ticket, gom kết quả, hỏi bạn khi cần quyết định.

Product Owner

Spec và ticket

Hỏi kỹ yêu cầu, viết spec để bạn duyệt, cắt thành ticket nhỏ có thứ tự trên GitHub.

Developer

Một người cho mỗi ticket

Viết test trước rồi code, tự review, dọn code, trong một nhánh và thư mục riêng. Nhiều người chạy song song.

Tester

Dùng thử như người thật

Chạy sản phẩm, bấm thử từng luồng, báo lỗi thành ticket mới trước khi merge.

Cập nhật không cần tải lại

Bản mới được đưa lên GitHub. Máy bạn kéo về bằng một trong hai cách:

  1. Nhấp đúp Cập nhật Team KID trên Desktop.
  2. Hoặc trong herdr, mở tab mới và gõ kid-update. Gõ kid-update --check để chỉ xem có bản mới không.

Cập nhật chỉ thay công cụ của Team KID (lệnh, KID Office, quy tắc). Code các app của bạn và GitHub Issues giữ nguyên.

Chạy ở đâu
